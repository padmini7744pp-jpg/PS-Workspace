The six editors

One workspace for everything you write, compute and present

Six real editors share one AI panel, one local search index and one theme system. No conversion layer, no cloud round-trip — every screenshot below is the shipped Windows build.

Docs .DOCX

Word editor, not a preview

Word documents open with their real layout — columns, headers, footnotes, shaded tables, floating images and pagination on Word's own line metrics.

  • Byte-preserving OOXML: styles, equations, ink, content controls
  • Tracked changes and comments with accept / reject
  • Mail merge with .xlsx or .csv and real MERGEFIELDs

Sheets .XLSX

Native Rust workbook engine

Values, formulas, formats, pivots and charts survive a save because nothing is flattened into a picture. A cell stays a formula.

  • Live recalculation, freeze panes, AutoFilter, number formats
  • Pivot tables, slicers, conditional formatting, formula tracing
  • Nine chart types and pictures stored inside cells

Slides .PPTX

A canvas that saves as PowerPoint

Design on a real slide canvas with masters, layouts, guides and non-destructive cropping — then hand PowerPoint a file it recognises.

  • Record narration with timings saved into the .pptx
  • Insert a .glb model and keep it 3D after saving
  • AI deck from one sentence, plus Beautify and Fact Check

PDF .PDF

Edit the page, not a sticker over it

PDFium rewrites the content stream with the original fonts, so text you retype really is the page's text.

  • Highlights, underline, strikethrough, notes and form fields
  • System OCR turns a scan into searchable text
  • PDF to Word, Excel or PowerPoint on this device

Markdown .MD

Plain files, no markup tax

A Tiptap block editor that writes straight back to plain .md — headings, lists, tables, code, Mermaid diagrams and KaTeX math.

  • [[Wiki links]], ![[embeds]], backlinks panel and graph view
  • Ask AI on a selection, with queued anchored edits
  • Local Markdown to Word export

HTML .HTML

AI page builder, brief first

Describe the page and the audience; the AI proposes a design brief — hook, palette, typography — then builds one self-contained file.

  • Live preview, split view and CodeMirror source
  • Click to select an element, double-click to edit text
  • Restyle by tokens; export to PDF or editable Word
The workspace

A home that knows where you left off

Recent files, every editor and the search index live on one calm screen. No dashboard, no sign-in, no news feed — and nothing to configure.

  • The four main formats are one click from a blank page, with dedicated Markdown and HTML cards
  • Recents: filter by format, sort by last opened, star a file, rename or reveal from its menu
  • Local full-text search over file names and extracted text in SQLite, CJK-aware
  • Every document opens in its own tab; the left rail keeps Home one click away

Bring your own key

Your model. Your key. Your document.

No account, no vendor proxy, no shared key. Every request goes directly from this machine to the provider you configured — and the app works fully without ever sending one.

17 providers, one custom slot

Pick a model, paste a key, and the same panel works in all six editors. It reads the open document's blocks — not a screenshot — so edits can land as tracked changes you can roll back.

  • Keys sealed with the OS credential vault (DPAPI), redacted in the UI, never written to logs
  • Test the connection without leaving the pane
  • Star files, then ask a question in plain language — every claim is cited and clickable
  • Image generation, media analysis and web search are separate opt-in providers

Automation

Tell your agent. Get real files.

The same engines are available headless: a CLI, an agent skill and an MCP server — so coding agents produce .docx, .xlsx, .pptx and .pdf instead of Markdown approximations.

CLI, 29 MCP tools, one skill

Create, read, edit, convert and render through the same engines — no runtime of its own, and documents never leave the machine.

  • Every command is an MCP tool, with the operation references as resources
  • Skill installs into Claude Code, Codex, Cursor, Gemini CLI, GitHub Copilot, OpenCode or Windsurf
  • A second local server lets an agent build in a visible editor tab while you watch

Privacy

Private by construction

No account. No telemetry. No analytics. No ads. No update pings. PS Workspace is a standalone desktop client — files open, edit, save, index and convert on this machine.

  • The local SQLite full-text index never leaves the machine
  • Network only for the AI or search request you trigger, to the provider whose key you added
  • Untouched parts of a .docx, .xlsx or .pptx are copied byte-for-byte
  • There is no analytics endpoint, crash reporter, update check or licensing server to receive anything
Installation help

Seeing "Windows protected your PC"?

That blue SmartScreen prompt appears for every newly released independent app — it is a warning about the missing code-signing certificate, not a virus detection. Here is how to get past it.

Run the downloaded setup fileDouble-click the PS Workspace setup from your Downloads folder.
Click "More info"On the blue window, click the small More info text under the message.
Click "Run anyway"A new Run anyway button appears at the bottom — press it and the installer continues.
Why this happens: I am an independent developer and have not bought a code-signing certificate yet, so Windows cannot verify the publisher. If you want proof, scan the installer with any antivirus you trust before running it — and please report anything odd through the Help button.

Why free

Why is PS Workspace free?

There is no account tier and no feature that needs a server, so nothing here can quietly become a subscription. If paid services like cloud sync ever arrive, they stay optional — the desktop app remains free and ad-free.

FAQ

Frequently asked questions

Is PS Workspace really free?

Yes — one install includes all six editors, the AI panel, Theme Studio, local search, PDF conversion and OCR, the CLI, the agent skill and the MCP server. No add-ons, no account tier, no ads.

Do I need an AI key to use it?

No. Every editor works without any AI at all. If you want it, add your own key for one of the 17 providers or any OpenAI-compatible endpoint — including a local model server. The key is sealed in the Windows credential vault and never appears in logs.

Will my Word, Excel and PowerPoint files still open in Office?

Yes. PS Workspace writes real OOXML and copies untouched parts byte-for-byte, so styles, comments, tracked changes, equations and content controls round-trip. Narration, timings and 3D models are stored the way PowerPoint stores them.

Does it work without internet?

Everything except an AI request. Rendering, OCR, conversion, indexing and export all run on this machine, and there is no update server phoning home.

Why does Windows SmartScreen warn me?

Because the installer is not code-signed yet, Windows cannot confirm who published it. Follow the installation help above, and scan the file with your own antivirus first if you want independent confirmation.

Which Windows versions are supported?

64-bit Windows — the current build is v0.12.0 for Windows x64. The screenshots on this page come from that shipped build.

How do I report a bug or ask for a feature?

Use the button in the header. Every message lands with me and I read all of them — that is how most of the feature list got built.
